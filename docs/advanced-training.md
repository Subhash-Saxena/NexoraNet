# Step 19: Advanced Cybersecurity Training Pathways

## 1. Skill Track Curricula

NexoraNet organizes its 40 defensive challenges into five structured career pathways designed to guide students from foundational analysis to expert-level incident correlation:

### Track 1 — Network Defender
- **Target Role:** Network Security Analyst
- **Difficulty Tier:** BEGINNER
- **Focus:** IPv4 addressing, RFC 1918 subnets, TCP 3-way handshake analysis, firewall ingress rules, packet dissection, and DNS client resolution.
- **Badge Awarded:** *Certified Network Defender*

### Track 2 — SOC Analyst
- **Target Role:** Tier 1 / Tier 2 SOC Analyst
- **Difficulty Tier:** INTERMEDIATE
- **Focus:** Alert triage, SIEM query formulation, event aggregation, IOC verification, correlation rules, and initial incident escalation.
- **Badge Awarded:** *Certified SOC Specialist*

### Track 3 — Network Detection
- **Target Role:** Detection Engineer
- **Difficulty Tier:** INTERMEDIATE
- **Focus:** Stealth port scanning signatures, DNS tunneling anomalies, beaconing frequency detection, Suricata/Snort rule crafting, and covert channel isolation.
- **Badge Awarded:** *Network Detection Specialist*

### Track 4 — Incident Investigator
- **Target Role:** Incident Responder / Forensic Analyst
- **Difficulty Tier:** ADVANCED
- **Focus:** Multi-host timeline reconstruction, Kerberoasting extraction, PsExec lateral movement detection, Golden Ticket forging analysis, and MITRE ATT&CK mapping.
- **Badge Awarded:** *Master Incident Investigator*

### Track 5 — Endpoint Investigator
- **Target Role:** Host & Endpoint Forensics Analyst
- **Difficulty Tier:** ADVANCED / EXPERT
- **Focus:** Process parent-child lineage, Living-off-the-Land (LOLBAS) binaries, scheduled task persistence, process hollowing, memory unhooking, and lateral credential dumping.
- **Badge Awarded:** *Endpoint Security Specialist*

## 2. Bloom's Taxonomy Pedagogical Matrix

Challenges are mapped across Bloom's revised taxonomy levels:

| Level | Goal | Example Challenge |
|---|---|---|
| **REMEMBER** | Recognize standard ports, protocols, and RFC ranges. | Identify Standard HTTP Port (`CHAL-BEG-005`) |
| **UNDERSTAND** | Interpret TCP flag combinations and DNS query formats. | Identify TCP Handshake (`CHAL-BEG-006`) |
| **APPLY** | Calculate subnet masks and filter packet logs. | Subnet Broadcast Address (`CHAL-BEG-007`) |
| **ANALYZE** | Correlate multi-source telemetry and isolate attack stages. | Kerberoasting TGS Request (`CHAL-ADV-006`) |
| **EVALUATE** | Assess containment trade-offs and evaluate threat severity. | Ransomware Staging Sequence (`CHAL-EXP-001`) |
| **CREATE** | Formulate detection rules and defense mitigation strategies. | Multi-Vector Incident Reconstruction (`CHAL-EXP-006`) |
